MD.Viewer

Drop md.php next to your docs and read

Self-hosted PHP Markdown viewer: automatic table of contents, heading numbering, Mermaid with auto-repair, glossary tooltips, copy buttons, dark mode and a built-in self-updater.

What it does

  • Auto table of contents and heading numbering
  • Mermaid diagrams with automatic repair
  • Self-updater with versioned backups and rollback

Built with

CSS, JavaScript, PHP, PowerShell
